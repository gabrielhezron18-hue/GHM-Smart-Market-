# GHM-Smart-Market-
The purpose of this project is to link Between Sellers and buyers through the web system through Advertising and orders through Web system

# Description
This system allows a client to login, create an order for goods he or she wants, truck his or her order, add orders, communicate with the sellers, pay for goods he or she chosed and view order status.
Also this systm allows and admin to login, view products, view orders, add goods, delete goods, update the order statuses of the clients and verifications of the orders.
It acts as the link between seller and the buyers of the goods.

# Features
- Login system
- Admin and user roles
- Product display, this is the main page showing the goods ready for sell and have a form used to create orders of goods by the clients
- Orders page, this is accessed only by the admin to view the list of orders

1. Install XAMPP
2. Put project in htdocs, where you will put it on the xampp folder 
3. Start Apache and MySQL
4. Open in browser
   NB: make sure you write the correct path.
